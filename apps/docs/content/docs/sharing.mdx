## Discord

**Settings -> Sharing** can update Discord rich presence. The Discord desktop client must be running. Optional application ID overrides the build-time `VITE_DISCORD_CLIENT_ID`.

## Local HTTP

Enable the server and set a port. Only `127.0.0.1` is bound. The JSON body is the now-playing snapshot; leave this off unless another app on the same machine needs it.
