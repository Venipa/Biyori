**Biyori** is an Electron app for tracking anime: AniList lists, a local library scan, playback matching, torrent RSS, Discord presence, and a local now-playing HTTP endpoint.

## Stack

- Electron + React (renderer)
- tRPC for main to renderer IPC
- SQLite (Drizzle) for local data
- Hana native worker/core
