---
title: Library
description: Scan local folders and match anime files to AniList series in Biyori.
---

Add folders under **Settings -> Library**. Biyori scans those paths, uses Hana (native worker/core) to parse filenames, and matches files to AniList series.

## Folders

- Use the folder picker on each row. Remove a folder with the trash button on that row (not a context menu).
- Recreate missing paths before expecting matches.

## Recognition

**Settings -> Recognition** controls how parsed titles map to list entries. After changing folders or rules, wait for a scan to finish before judging matches.

## Fixing matches

Open a library folder from **Library** to see which anime each series folder is matched to. From the folder sheet you can assign an anime (also ones not on your list), rematch, or ignore a folder.

When one folder holds episodes of more than one AniList entry (split cours, absolute numbering, `S00` specials), add an [episode rule](/docs/library-rules).
