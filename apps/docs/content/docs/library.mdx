---
title: Library
description: Scan folders and match local files
---

Add folders under **Settings -> Library**. Biyori scans those paths, uses Hana (native worker/core) to parse filenames, and matches files to AniList series.

## Folders

- Use the folder picker on each row. Remove a folder with the trash button on that row (not a context menu).
- Recreate missing paths before expecting matches.

## Recognition

**Settings -> Recognition** controls how parsed titles map to list entries. After changing folders or rules, wait for a scan to finish before judging matches.
