AniList is the default list service. MyAnimeList and Kitsu are not available yet.

## Connect

1. Open **Settings -> Services**.
2. Use **Connect** to authorize in the browser, or paste a personal access token.
3. Disconnect from the same panel. Account changes save immediately and are not part of the main settings Save bar.

## What syncs

Lists, progress, and series details come from AniList. Title language (Romaji, English, Native) is set under **Settings -> Application**.

Build-time env `VITE_ANILIST_CLIENT_ID` is required for the OAuth client used by Connect.
