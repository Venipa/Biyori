## Downloads

Grab the latest build from the [landing page](/) (OS is auto-detected) or from GitHub Releases.

| Platform | Artifact | Notes |
| --- | --- | --- |
| Windows | `*-setup.exe` (NSIS) | Current releases |
| macOS | `.dmg` / `.zip` | Shown when published |
| Linux | `.AppImage` / `.deb` | Shown when published |

## First launch

1. Install the Windows setup (or unpack another OS build when available).
2. Open **Settings -> Services** and connect AniList.
3. Add library folders under **Settings -> Library** if you keep local files.

## Updates

Official builds use electron-updater against GitHub Releases. Pick **stable**, **beta**, or **alpha** in Settings or About.
